# SLUJ Character

The SLUJ character is not decorative branding.

The character represents SLUJ itself — the little agent/creature that digs
through project sludge, discovers context, remembers what belongs to a
project, and quietly keeps watch over it.

The character should feel:

- alive
- weird
- lovable
- subtle
- useful
- lightweight
- technically competent
- playful without becoming childish

The character should never become:

- a noisy mascot
- constant animation
- a cartoon assistant interrupting the user
- decorative motion with no relationship to product state

## Character states

### Idle

Tiny breathing, squish, wobble, or subtle sludge movement.

SLUJ is alive but waiting.

### Listening

SLUJ subtly reacts when the user is entering a project or giving it something
to investigate.

Could lean, perk up, stretch, or become slightly more attentive.

### Digging

SLUJ becomes visibly active while discovering project context.

This is the primary motion state during DIG.

Motion could include:

- churn
- wobble
- ripple
- squish
- subtle morphing

It should communicate active investigation without becoming a generic loading
spinner.

### Found

A small reaction when SLUJ discovers something relevant.

Examples:

- quick pop
- bounce
- stretch
- satisfied movement

Keep it brief.

### Thinking

Slow, subtle movement while SLUJ is resolving or connecting information.

Could feel slightly suspended, morphing, orbiting, or contemplative.

### Messy

Used when SLUJ detects meaningful project clutter, inconsistency, unusual
storage, or unresolved project state.

The character may look mildly concerned or slightly agitated.

Do not make this alarming or judgmental.

### Done

SLUJ finishes a task or discovery pass and settles back into a calm state.

Could include:

- tiny satisfied bounce
- settling motion
- relaxed squish
- return to Idle

## Relationship to BOOT → DIG → PROJECT

**BOOT** — SLUJ is mostly Idle / Listening.

**DIG** — SLUJ becomes active. Digging, Thinking, and Found states appear as
project context is discovered.

**PROJECT** — SLUJ settles into a quieter persistent presence. Idle is the
default, with subtle state changes when the project needs attention.

## Motion principle

The user should occasionally notice:

> "Oh. SLUJ is alive."

They should not think:

> "Why is this mascot constantly moving?"

Motion should be:

- subtle
- smooth
- premium
- lightweight
- purposeful
- state-driven

The SLUJ character is the product agent made visible.
