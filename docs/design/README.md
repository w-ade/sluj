# Design explorations

The current app follows page **SLJ-20261003-002** in
[Sluj](https://www.figma.com/design/4khVMC4ZIIyr9L7Pqnf7nx/Sluj?node-id=50-39):
500 × 396 cards, equal-width vertical columns, per-process values and labels,
and Fine / Busy / Heavy states for each metric in light and dark modes.
Memory references: `50:41` (light card), `50:4297` (dark card).
The older exports below document the previous horizontal-strip design.
